# The Awareness Group — CMO Weekly Report Generator

A web app that lets you type short notes and auto-fills a professional CMO Weekly Report using AI, then downloads it as a formatted Word document.

## How to run

```bash
pip install -r requirements.txt
python app.py
```

Then open **http://localhost:5151** in your browser.

## How to use

1. Paste your Anthropic API key into the field at the top
2. Fill in short notes in any section (bullet points, fragments — anything)
3. Click **Auto-Fill with AI** to expand everything into polished prose
4. Click **Download Word Report** to get the `.docx`

## Sections covered

1. Marketing Executive Summary
2. Marketing Objectives (Planned vs. Completed)
3. Key Marketing Metrics & KPIs
4. Major Wins & Deliverables
5. Strategic Marketing Initiatives
6. Cross-Functional Alignment
7. CEO Decisions / Support Needed
8. Priorities for Next Week
9. CMO Comments & Strategic Notes
